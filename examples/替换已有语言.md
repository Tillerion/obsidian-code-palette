# 替换已有代码块语言

右键本文件 → **代码配色：设置语言规则**：

1. 默认语言选择 **Markdown**。
2. “已有代码块语言”选择 **替换为指定语言**，保存规则。
3. 在阅读视图或实时预览查看效果；全局配色可以保持开启，文件规则始终优先。

下方围栏原文仍写着 `text`，但阅读和实时预览会显示为 Markdown 正文；源码模式可继续编辑原文。实时预览中也可双击正文块进行编辑。

```text
# Markdown 标题

**粗体文字**、`行内代码` 和 [链接](https://obsidian.md)。

- 列表项目
> 引用内容
```

改回“保留已有语言（默认）”，即可恢复纯文本显示。
