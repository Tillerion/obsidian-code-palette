# 代码配色演示

为本文件或所在文件夹设置 **Python**，再选择一套代码配色。

正文与标题仍使用 Obsidian 当前主题。行内代码示例：`return False`、`len(items)`、`"Hello, Obsidian!"`。

| 方法 | 找到时 | 没找到时 |
| --- | --- | --- |
| `find(sub[, start[, end]])` / `rfind` | 首次 / 最后一次的原串下标 | `-1` |
| `index(...)` / `rindex` | 首次 / 最后一次的原串下标 | `ValueError` |
| `count(sub[, start[, end]])` | 不重叠出现的次数 | `0` |
| `startswith(prefix[, start[, end]])` / `endswith(suffix[, start[, end]])` | 匹配指定范围的开头 / 结尾 | `False` |

## 未标注的代码块：使用默认 Python

```
def greet(name):
    # 多语言代码配色
    return f"Hello, {name}!"

print(greet("Obsidian"))
```

## 已有语言标记：继续使用 C++ 和 Java

```cpp

int main() {
    /* 多行注释

```

```java
public class Demo {

```
