# Code Palette 0.3.1

## 中文

- 新增正文代码识别，沿用全部 24 种语言，支持未加反引号的代码行和题干片段。
- 在文件／文件夹规则中分别手动开启，默认关闭；全局配色和仓库默认行为保持不变。
- 仅调整文字颜色，保留原文、排版和复制内容；保护已有代码、链接、双链、属性、公式与功能块。
- 支持 Python 列表、下标、多行表达式和 SQL 分行查询；保留原生 Markdown／HTML／XML 正文结构。
- Notebook Navigator 单文件、文件夹右键菜单可直接设置规则或恢复继承，自动处理加载顺序及卸载。
- 继续提供 ZIP 安装包；更新时覆盖三个安装文件并保留 data.json。

## English

- Recognize unmarked exercise code with all 24 bundled language profiles, including standalone code and snippets inside questions.
- Enable each switch manually in file/folder rules. Both default off; global palette and vault defaults never scan prose.
- Change text colors only, preserving source, layout, clipboard text, protected code, links, properties and formulas.
- Handle Python arrays/subscripts/multiline expressions and multiline SQL; preserve native Markdown/HTML/XML rendering.
- Integrate Notebook Navigator single-file/folder context menus with the same rule and inheritance actions.
- Include the installation ZIP. Preserve data.json when replacing installation files.
