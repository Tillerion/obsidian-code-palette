# Code Palette 0.3.2

## 中文

- 修正 0.3.1 社区扫描中的 HTML 解析阻断项；隔离文档仅用于读取结构，解析节点不插入笔记。
- 包含本轮全部功能：24 种语言的正文代码识别、独立代码段／题干片段开关，以及 Notebook Navigator 文件／文件夹右键规则入口。
- 正文识别仅在手动开启的文件／文件夹规则中生效；全局配色与仓库默认行为不变。
- 保留笔记原文、复制内容与排版；更新时覆盖三个安装文件并保留 data.json，继续提供 ZIP 安装包。

## English

- Fix the HTML parsing operation rejected by the 0.3.1 community scan. Read structure in an isolated document without inserting parsed nodes into notes.
- Include all new features: 24-language unmarked exercise-code recognition, separate standalone/question switches and Notebook Navigator file/folder rule menus.
- Recognition remains opt-in for explicit file/folder rules. Global palette and vault defaults keep their existing behavior.
- Preserve source, clipboard text, layout and settings. Keep data.json when updating; an installation ZIP is included.
