# Code Palette 0.1.3

## 🛠️ 中文

- 修正社区审核阻断项：设置页标题使用 Obsidian `Setting.setHeading()` 接口。
- 阅读和编辑视图的延迟刷新使用所属窗口的计时器，改善独立弹出窗口的生命周期兼容性。
- 修正异步选择回调类型、DOM 创建方式、配置快照类型和未使用导入。
- 清单描述符合英文标点要求，主 README 增加英文简介。
- 社区发布只提供 `main.js`、`manifest.json`、`styles.css` 三个安装附件；构建流程生成并核验 GitHub 来源证明。
- 保持 0.1.2 的高亮规则、配色、配置格式和最低 Obsidian 版本不变。

## English

- Use the standard Obsidian setting heading API to resolve the blocking community review finding.
- Schedule reading/editor refresh timers in their owning window, including popouts.
- Correct asynchronous picker callback types, DOM helpers, snapshot typing and an unused import.
- Use an English manifest description ending in a period and include an English overview in the main README.
- Publish only the three supported installation assets, built and attested through GitHub Actions.
- Keep existing highlighting behavior, saved configuration and Obsidian 1.8.0 compatibility.

Verification details and remaining advisory findings are recorded in `docs/verification.md`. No foreground Obsidian testing was performed for this release.
