# Code Palette 0.3.0

## 中文

- 修复连续编辑时在原生配色与插件配色之间闪烁：随编辑映射已有词元，持续保留基础色，新结果准备好后统一替换。
- 光标移动不重新着色普通代码；增量 Markdown 解析和代码块缓存减少大笔记输入时的重复计算。
- Markdown 正文预览增加独立开关，默认开启以兼容现有配置。关闭后语言替换仍可用于语法高亮。
- Markdown 块进入编辑后持续保持源码状态，光标移出不再自动恢复预览。点击“完成编辑”或运行“完成 Markdown 编辑并恢复正文预览”命令后恢复正文；输入法组合期间禁止该切换。
- 保留语言规则优先级、全局配色兜底、笔记原文、已有语言与主题及功能块保护。继续提供 ZIP 安装包。

## English

- Keep existing code colors throughout typing and apply validated token updates together, eliminating the clear-before-highlight cycle.
- Avoid recoloring ordinary code on cursor movement. Incremental Markdown parsing and per-block caching reduce repeated work.
- Add an independent Markdown body-preview toggle, enabled by default for existing configurations; syntax language replacement still works when it is disabled.
- Keep Markdown blocks in source-editing mode until Finish editing is clicked or the corresponding command runs. Moving the cursor away no longer restores the preview. Finish is blocked during IME composition.
- Preserve source text, scope priorities, global fallback, bundled languages/themes and functional-block exclusions. Include the installation ZIP.
