# Code Palette 0.2.0

## ✨ 中文

- 语言规则新增“已有代码块语言”：可选择“保留已有语言（默认）”或“替换为指定语言”。
- 例如将规则语言设为 Markdown，再启用替换，即可让标为 `text` 的普通代码块按 Markdown 高亮。
- 文件、文件夹及仓库默认规则均支持；阅读、实时预览和源码模式共用语言选择策略。
- 替换只改变显示，不改写代码内容或围栏标签；Mermaid、Dataview 等已知功能块继续排除。
- 旧规则默认保留已有语言。全局配色模式仍不推断语言，暂时绕过语言规则，关闭后恢复。
- 附带 ZIP 安装包及三个独立安装文件；均通过 GitHub Actions 构建与来源证明核验。

用法：右键文件／文件夹 → 代码配色：设置语言规则 → 默认语言选择 Markdown → 已有代码块语言选择“替换为指定语言”。使用语言规则时，请关闭全局配色模式。

## English

- Add a per-rule policy to preserve existing code-block languages (default) or replace them with the selected rule language.
- Highlight `text`-labelled Markdown snippets as Markdown without editing their contents or fence labels.
- Support file, folder and vault-default rules across reading and editor views; known functional blocks remain protected.
- Existing settings keep preserve behavior. Global palette mode continues to avoid language inference and bypasses saved language rules until disabled.
- Include a ZIP and the three installation files, built and attested through GitHub Actions.

Choose a scope's rule language, select the replacement policy, and leave global palette off. Replacement affects all ordinary blocks in that scope, not just `text` blocks.

Verification is limited to background tests, builds and review; no foreground Obsidian acceptance testing was performed for this release.
