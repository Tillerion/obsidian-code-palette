# Code Palette 0.2.1

## 中文

- 修正 Markdown 替换的显示行为：阅读视图和实时预览将块内容渲染为真正的 Markdown 正文，包括标题、列表和表格。
- 实时预览可双击进入原文编辑，移出光标后恢复预览；源码模式保留原始围栏和内容。
- 全局配色改为兜底：文件、文件夹及仓库默认规则优先，替换策略、禁用范围和代码类型开关不再被覆盖。
- 保留 Markdown 原文、普通代码高亮和已知功能块保护；取消异步渲染或关闭规则后恢复原代码块。
- GitHub 发布继续提供 ZIP 和三个安装文件。

## English

- Render replacement blocks targeting Markdown as actual Markdown body in reading and live-preview views.
- Double-click a live preview to edit the original source; move outside the block to restore it. Source mode remains editable and unchanged.
- Use global palette only for unmatched notes. File, folder and vault-default rules, exclusions and per-type switches take precedence.
- Preserve source text, known functional blocks and ordinary syntax highlighting, with cleanup for cancelled previews.
- Include the installation ZIP and three standalone assets.
